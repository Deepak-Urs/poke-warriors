# **Poke Warriors** 🎮

A fun and interactive Pokémon battle game where players engage in turn-based battles with their chosen Pokémon against a randomly selected opponent.

## **Features**
- **Choose Your Warrior**: Pick your Pokémon from a list, complete with portraits, types, HP, and moves.
- **Turn-Based Battles**: Select moves strategically to defeat the opponent while managing your Pokémon’s HP.
- **Dynamic Gameplay**: Opponent Pokémon responds with random moves, making each battle unique.
- **Real-Time Updates**: Track health, moves, and outcomes directly on the user interface.
- **Replayability**: Start a new battle once a match concludes.

## **Tech Stack**
- **Frontend**: React, HTML5, CSS3
- **State Management**: Redux (if applicable)
- **API/Mock Data**: Fetch Pokémon details using mock API or local JSON files
- **Styling**: Responsive CSS for dynamic layouts

## **Installation and Setup**
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Deepak-Urs/poke-warriors.git
   cd poke-warriors
   ```

2. **Install Dependencies**:
   Ensure you have [Node.js](https://nodejs.org/) installed. Run:
   ```bash
   npm install
   ```

3. **Start the Development Server**:
   ```bash
   npm start
   ```
   Navigate to `http://localhost:3000` to play the game.

## **Usage**
1. Launch the app in your browser.
2. Select your Pokémon from the available options.
3. Engage in turn-based battles by selecting moves.
4. The battle continues until one Pokémon’s HP drops to zero.
5. Play again by starting a new battle.
